# Поиск мультфильмов по описанию

Расширяемый каркас решения задания из [README.txt](README.txt).
Факты берутся только из `catalog.json`; исходные данные и 10 вопросов сохранены.

Сейчас реализованы модели, контракты интеграций, индексация через контракты,
общий сценарий обработки запроса, проверки ссылок и утилиты оценки.
Адаптеры Qdrant, embedding-модели, планировщика запросов и генератора ещё
не подключены. Поиск и прогоны A/B пока не доступны.

## Локальная проверка

Python 3.11+; для проверки каркаса внешние зависимости не нужны.
Выполнять из корня проекта:

```bash
PYTHONPATH=src python3 -m cartoon_rag.cli validate-data
PYTHONPATH=src python3 -m unittest discover -s tests -v
```

После установки пакета через `python3 -m pip install -e .` доступна команда
`cartoon-rag validate-data`. Установка требует наличия сборочных зависимостей.

## Структура

| Файл | Ответственность |
| --- | --- |
| `src/cartoon_rag/domain.py` | Карточки, фрагменты, фильтры, план запроса, ответ, трасса |
| `src/cartoon_rag/ports.py` | Контракты моделей, индекса, поиска и точных операций |
| `src/cartoon_rag/ingestion.py` | Загрузка, выбор ревизий, подготовка embedding-текста, публикация снимка |
| `src/cartoon_rag/application.py` | Маршрутизация запроса, группировка, генерация, проверка источников |
| `src/cartoon_rag/evaluation.py` | Загрузка вопросов, Recall@k, контракт смысловой оценки, сохранение трасс |
| `src/cartoon_rag/cli.py` | Проверка исходных данных |
| `tests/` | Проверки архитектурных инвариантов на тестовых адаптерах |
| `configs/` | Место для конфигураций реальных экспериментов |
| `artifacts/` | Место для результатов реальных прогонов |

Порядок подключения адаптеров и правила расширения описаны в
[docs/architecture.md](docs/architecture.md).
