# Агенты проекта

В этой папке хранятся переиспользуемые инструкции для специализированных ролей.
Общие требования проекта остаются в корневом `AGENTS.md`.

| Агент | Профиль | Назначение |
| --- | --- | --- |
| Ревьюер кода | [code-reviewer.md](code-reviewer.md) | Проверка изменений, воспроизведение ошибок и отчёт с приоритетами |

Пример запроса:

> Используй профиль agents/code-reviewer.md и проведи ревью незакоммиченных изменений.

Для запросов на ревью корневой `AGENTS.md` предписывает прочитать этот профиль.
Это инструкции для работы в текущей сессии; отдельный процесс или регистрация
субагента в настройках Codex этими файлами не создаются.

Новые роли добавляйте отдельными файлами и перечисляйте в таблице выше.
