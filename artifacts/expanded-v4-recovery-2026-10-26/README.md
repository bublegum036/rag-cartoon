# Отдельный повтор двух технических ошибок v4

26 октября 2026 повторены sea-short и count-all — все и только случаи
с HTTP 503 из первого четырёхвопросного прогона v4. Вход:
[questions-expanded-v4-recovery.jsonl](../../data/questions-expanded-v4-recovery.jsonl).
Prompt v4, runtime, вопросы, rubric и подготовки совпали с исходными.
Python-код не менялся; базовый коммит `7a2ac32`.

План предусматривал полный набор 20 вопросов, если оба ответа будут приняты.
Числа восстановлены, но один ответ содержит неподтверждённый мотив, поэтому
условие не выполнено и полный прогон **не запускался**. По умолчанию остаётся v2.

Модель gemini-3.1-flash-lite, prompt grounded-ru-v4, лимит 2048,
retrieval_k=10, context_movies=3, пауза 10 секунд, тот же физический снимок
cartoons-expanded. Это один вручную запрошенный повтор двух вопросов;
автоматических повторов внутри прогона, смены модели или включения биллинга нет.

### sea-short: число вернулось, фактическая проверка не пройдена

[Ответ](sea-short/answer.json) явно сообщает 78 минут и соответствие <90,
называет правильный фильм и описывает дружбу и ремонт маяка. Rubric теперь
выполнен; фильтр и film-01#plot корректны.

Но text утверждает: «В благодарность кит помогает Нике». Карточка сообщает
о спасении кита, а затем его помощи, не приписывая мотив благодарности.
Такой же мотив уже отклонялся в [оценке v3](../expanded-retry-v3-2026-10-26/reviews.json).
Сам prompt v4 запрещает выводить мотивы только из порядка событий.
Поэтому facts_supported=false при rubric_passed=true. Критерий не изменён
после ответа; восстановление числа не отменяет требование опоры на карточку.

### count-all: принят

[Ответ](count-all/answer.json) сообщает 40 фильмов. ExactResult=40,
контекст содержит все 40 карточек, source_ids перечисляет все 40 источников
без повторов. Подсчёт выполнен кодом по полному снимку, не по top-k.

## Что подтверждено и что нет

В этой отдельной попытке v4 сохранил требуемую длительность и правильно
оформил точный подсчёт. Это наблюдение двух ответов, не гарантия устойчивости
prompt. Ошибок API здесь нет, но устранение HTTP 503 у провайдера не доказано.
Неподтверждённое сюжетное уточнение сохранилось несмотря на прямую инструкцию.

Codex прочитал весь text и reason, сверил все четыре флага приёмки.
Проверка не независимая и не слепая. Нельзя объявить 2/2 на основании только
правильных чисел: для приёмки нужны также факты, ограничения и источники.
Два прогона v4 не объединялись в результат одного прохода; исходные 2/4
с техническими ошибками и исходный полный результат 16/20 не менялись.
