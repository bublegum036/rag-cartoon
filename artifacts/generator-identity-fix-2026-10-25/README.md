# Исправление метаданных генератора

`before.json` воспроизводит несоответствие настроек переданного генератора
и метаданных прежней фабрики без сетевых запросов. `tests-before.log` —
ожидаемо неуспешный запуск регрессионных тестов до исправления фабрики.

После исправления `tests-local.log`: 127 тестов, 124 прошли,
3 интеграционных пропущены. Четыре новых теста проверяют явную identity,
отклонение противоречий, штатную конфигурацию и manifest оценщика.
`validate-data.json`: 12 активных карточек, 10 случаев.

Провайдеры не вызывались. Сохранённые A/B-прогоны не изменялись.
