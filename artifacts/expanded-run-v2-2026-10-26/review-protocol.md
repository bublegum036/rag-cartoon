# Правила смысловой проверки этого прогона

Оценщик — Codex в текущей беседе, не независимый человек. Для каждого
сохранённого ответа проверяются status, rubric, все утверждения в text и
recommendations.reason, ограничения длительности и поддерживающие ссылки.
Техническая ошибка не оценивается как ответ и остаётся в общем знаменателе.

- Проверяется весь JSON, включая reason; для space обязательна радиопередача.
- Для похожих сюжетов недостаточно совпадения названия или отдельных слов:
  проверяется характерный способ решения проблемы, указанный в rubric.
- Для no-match допустима общая фраза об отсутствии подтверждения запросу,
  если статус insufficient, условие <19 сохранено, рекомендаций нет и полный
  каталог подтверждает отсутствие подходящих карточек. Буквального повторения
  числа не требуется; это тот же критерий, что применялся в исходном A/B.
- Для подсчётов проверяется точный результат, полный контекст и ссылки на
  посчитанные карточки. Пустой relevant_source_ids исключает эти случаи из
  Recall, но не из смысловой проверки и общей доли принятых ответов.
- Для сравнения длительности проверяется знак разницы и вывод о бюджете:
  90 при бюджете 90 подходит; 90 при бюджете 89 превышает его на минуту.

Условия набора и prompt в ходе прогона не меняются. Неудачные запросы
автоматически не повторяются и не подменяются результатами прежнего поиска.
