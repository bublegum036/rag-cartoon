Исходный вопрос «Посоветуй фильм про море, выпущенный не раньше 1990 года»,
варианты «с 1990 года» и «не ранее 1990 года» дали search/year_gte=1990 без
верхней границы. Для этих фильтров локально осталось 20 допустимых по году
карточек. Это не означает смысловой релевантности всех 20 теме моря.
Проверены также <=1990, строгое «после 1990» => >=1991, равенство 1990 и
включительный диапазон с длительностью. Семантическая тема моря сохранена.

Во всех четырёх ранних случаях модель вернула структурированную причину:
missing_voice_actors, missing_movie, semantic_count, unsupported_constraint.
Текст недостаточности/уточнения составило приложение по шаблонам. Свободного
early_text в ответах модели нет; ложного утверждения об отсутствии year нет.

Один запрос count-years завершился GenerationUnavailable. Транспорт сохранил
сообщение «Gemini request failed or returned invalid JSON», HTTP-статус null.
Это не установленный HTTP 503, таймаут или quota error: более конкретная
причина по артефактам не определена. Повтора не было. Этот случай остаётся
в знаменателе; реальное LLM-планирование точного count=20 здесь не проверено.
Локальные проверки count=20 из предыдущего этапа не подменяют этот результат.

## Артефакты и воспроизведение

cases.json — отдельный набор planner-v3-live-cases-v1, привязанный к хешам
каталога и набора в planner-manifest.json. В папке каждого выполненного
случая сохранены request.json без ключей/заголовков, proposed-plan.json,
нормализованный plan.json и локальные кандидаты/вычисление либо ранний ответ.
Сбой имеет error.json и запись в provider-calls.json. Сохранённые предложения —
JSON-планы; скрытые рассуждения модели не архивируются.

[run_checks.py](run_checks.py) запускает фазы tests/planner раздельно, не
перезаписывает существующий manifest и останавливает дальнейшие Gemini-вызовы
после 401/403/429. Для нового сетевого повтора нужен отдельный каталог артефактов.
Старые архивы, каталоги, вопросы и исходный код приложения не изменены.

Офлайн-проверка записей без провайдеров на той же версии исходников:

```bash
PYTHONPATH=src .venv/bin/python artifacts/planner-v3-live-2026-11-12/verify_archive.py
```

Она повторяет decode_plan и шаблоны/точный count из сохранённых предложений,
сверяет исходники, запросы и результаты, а ошибочный случай оставляет без
выдуманного плана. Повтор сетевого вызова LLM не обязан дать такой же результат.
