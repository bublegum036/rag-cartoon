# Исправление захвата операнда вместо условия года — 2026-11-12

Подтверждено замечание P2: «про море с 1990 года» и «про море не ранее 1990 года»
в ru-rules-v1.2 превращались в равенство 1990. _YEAR_EXACT захватывал операнд
нераспознанного оператора. На неизменном расширенном каталоге это давало одну
карточку вместо 20 кандидатов с year>=1990.

В ru-rules-v1.2.1 нижняя граница разбирается целиком: с/начиная с/не ранее/
не раньше. Добавлены также ранее/позднее/не позднее. Перед точным годом
проверяются оставшиеся маркеры отношения: неподдерживаемые «от», «новее»,
«старше», «не моложе» и незавершённое «с 1990 года по» дают clarify.
Явный точный год и полный включительный диапазон продолжают работать.

[До исправления](before-fix-tests.log) регрессионные случаи падали.
[После исправления](tests-local.log): 190 тестов, 186 прошли,
4 интеграционных пропущены. Проверяются план, набор всех 20 допустимых по году
карточек и точный count=20 с полными source_ids. Эти 20 — кандидаты по году,
не утверждение о том, что все они соответствуют теме моря.
Оба каталога валидны, git diff --check проходит. Провайдеры не вызывались.
Реальные Qdrant/E5 после этой правки не перезапускались; их предыдущие
189 успешных проверок относятся к предыдущему этапу.

[regression.json](regression.json) сохраняет планы, ID кандидатов до/после,
фильтр Qdrant, точный результат, версии, хеши кода и каталога. Прежние архивы
и данные не переписывались. Для воспроизведения снимок дефектного планировщика
сохранён в rule_planner-before-fix.py.

```bash
PYTHONPATH=src .venv/bin/python artifacts/year-operator-fix-2026-11-12/verify.py
```
