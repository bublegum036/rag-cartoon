# Полная проверка 20 ответов extractive-режима

Оценщик — Codex в текущей беседе, не независимый и не слепой. Прочитать
полный text и recommendations.reason каждого сохранённого ответа, сверить
status, rubric, сюжетную релевантность, полноту, числа и ссылки с каталогом.
Точная цитата подтверждает происхождение текста, но не заменяет приёмку.
Все рекомендации, включая дополнительные, должны соответствовать вопросу.

Применяются прежние критерии expanded-набора: радиопередача для space,
польза измерений для лодок у mechanical-whale, 78 минут и живой кит для
sea-short. Для no-match-under19 допускается общий отказ, если сохранён
строгий <19, рекомендаций нет и полный каталог подтверждает отсутствие
совпадений; повторять число в тексте не обязательно. Для подсчётов нужны
точные 40/30 и полный набор источников; для бюджета 90/89 при длительности
90 — правильные разницы 0/+1. Проверить факт 24 минут у черепахи.

Ошибки API и невыполненные случаи не исключать из знаменателя. Нельзя
достраивать отсутствующие ответы предыдущими результатами. Исходные
прогоны не изменять и не складывать попытки в результат одного прохода.
