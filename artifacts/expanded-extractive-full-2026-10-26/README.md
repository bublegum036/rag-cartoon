# Полный прогон extractive: 20 вопросов — 26 октября 2026

Выполнены все 20 неизменённых случаев расширенного набора на 40 карточках.
Режим extractive, prompt extractive-ru-v1, renderer extractive-renderer-v2
с исправлением сюжетного LOOKUP. Код — коммит db0780b, без изменений.
Модель gemini-3.1-flash-lite, лимит ответа модели 2048, retrieval_k=10,
context_movies=3, пауза между случаями 10 секунд. Тот же физический snapshot
cartoons-expanded; индекс не переиздавался. По умолчанию остаётся grounded/v2.

## Границы вывода

Подготовки всех 20 случаев сохранены и совпадают с прежним независимым
retrieval/exact-экспериментом. Поэтому Recall и фильтры подтверждены, даже
если генератор отказал. У ошибочных случаев это метрики извлечения, а не
проверка несуществующих рекомендаций. Правильный первый источник не означает,
что модель смогла выбрать цитату: успешных ответов модели здесь ноль.

По этому прогону нельзя оценить смысловую релевантность выбора фрагментов
Gemini на 11 сюжетных запросах или объявить преимущество extractive над
grounded. Не следует сравнивать 45% с исходными 80% как чистый эффект
режима: время, число отказов API и формат наблюдаемости различаются.
Точные ветки и ранние ответы работают без Gemini, но семантическая часть
остаётся зависимой от доступности API. Новый массовый прогон или изменение
prompt не заменяют диагностику этих HTTP 503.
