# Годовые фильтры — 2026-11-12

Реализованы включительные year_gte/year_lte для планировщиков, CLI,
Qdrant-предфильтра, точных операций и оценки строгих условий. Год больше
не является причиной раннего отказа. Числовые типы/границы и диапазон
проверяются кодом, смысловой top-k не используется для подсчёта.

Версии: ru-rules-v1.2; Gemini planner/prompt gemini-plan-ru-v3;
planner-decoder-v4; early-replies-ru-v2; архив 3; stage-quality-v2.

[Примеры и проверка](verification.json):

- Исходный вопрос про море «не раньше 1990 года» даёт search/year_gte=1990.
- Годовой диапазон сочетается с duration_minutes <90 в одном Qdrant filter.
- Подсчёт по расширенным 40 карточкам за 1980–1990 годы и <90 минут даёт 7.
- Подсчёт за 1900 год даёт точный ноль.
- Named lookup сохраняет ограничение года.
- Восемь прежних архивов прочитаны с проверкой хешей/reviews; метрики и все
  исходные файлы совпали. Отдельные тесты также пересчитывают их копии.

[Реальный прогон](tests-live.log): **189 тестов прошли без пропусков** с
Qdrant 1.17.0 и E5 из закреплённого кэша. Новый тест DB проверяет, что фильм
с высоким score исключается длительностью, старый короткий — годом, а top-1
выбирается из оставшегося набора. Проверены точный 1990 год, верхняя граница
1989 и пустой результат >=1992. Коллекции тестов имеют случайные alias;
основные снимки не перепубликовывались. Годовой DB-тест специально не создаёт
payload-index для year и проверяет его отсутствие: существующие коллекции
с полем year в payload также фильтруются без переиндексации.

[Локальный прогон](tests-local.log): 189 тестов, 185 прошли,
4 интеграционных пропущены. Оба каталога проходят validate-data.
Новый Gemini-контракт проверен транспортной заглушкой; реальных Gemini-вызовов
не было. Это не новый A/B и не оценка смыслового качества рекомендаций.

Новые архивы используют схему 3. Для старых схем nullable-расширение Filters
восстанавливается только для проверки первоначальных хешей: реальные годовые
ограничения запрещены в схемах 1/2. Функция fingerprint не менялась.
