# Точные операции над каталогом — 25 октября 2026

Реализованы `JsonExactCatalog`, общий сценарий `execute_exact` и CLI `exact`.
Проверка выполнена на Python 3.13.15, без обращения к Qdrant/E5.
Новых зависимостей нет; каталог и исходные вопросы сохранены.

## Команды и результаты

Из корня проекта:

```bash
PYTHONPATH=src python3 -m unittest discover -s tests -v
PYTHONPATH=src python3 -m cartoon_rag.cli validate-data
PYTHONPATH=src .venv/bin/python -m cartoon_rag.cli exact "Сколько минут длится „Маяк для кита“?"
PYTHONPATH=src .venv/bin/python -m cartoon_rag.cli exact "Сколько фильмов в каталоге?"
PYTHONPATH=src .venv/bin/python -m cartoon_rag.cli exact "Сколько мультфильмов короче 90 минут?"
PYTHONPATH=src .venv/bin/python -m cartoon_rag.cli exact "Сколько фильмов короче 40 минут?"
PYTHONPATH=src .venv/bin/python -m cartoon_rag.cli exact "Подойдёт ли «Коралловая почта», если у меня только 90 минут?"
git diff --check
```

- [tests-local.log](tests-local.log): всего 88 тестов, 85 прошли,
  3 интеграционных пропущены. Добавлен 21 тест точных операций.
- [validate-data.json](validate-data.json): 12 активных карточек, 10 вопросов.
- [lookup.json](lookup.json): полная карточка film-01, длительность 78,
  `exact_result: null`; источник `film-01#plot`, без синтетических chunks.
- [count-all.json](count-all.json): 12 фильмов, полное множество источников.
- [count-short.json](count-short.json): 9 фильмов при `< 90`.
- [count-zero.json](count-zero.json): вычисленный 0, пустые контекст и ссылки.
- [compare.json](compare.json): film-02, 96 − 90 = +6 минут,
  источник `film-02#plot`. Слишком длинная карточка сохранена для вычисления.
- [manifest.json](manifest.json): хеши данных/адаптера и проверенные значения.

В тестах также проверены отрицательная/нулевая разница длительности,
границы `<`/`<=`, фильтры ID без дублей, последняя активная версия, переход
film-01 с 78 на 92 только на временных данных и неактивная последняя версия.
COUNT возвращает 12 даже при `retrieval_k=1` и `context_movies=1`.
Нулевой подсчёт и отсутствующая карточка имеют разные результаты.
Ошибки файла/провайдера не подменяются отсутствием фильмов.

CLI загружает каталог один раз и использует те же ревизии для планирования
и точных операций. Проверены работа без `.env`/embeddings, другой JSON-файл,
ранние статусы и отказ выполнить семантический поиск как точную операцию.
Через `SearchService` проверена передача результатов в генератор-заглушку.
